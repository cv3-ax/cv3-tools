# cv3-tools — CV3-AX 사내 Claude Code 플러그인 마켓플레이스

사내 Claude Code 플러그인을 배포하는 마켓플레이스입니다. 이 repo 하나만 추가하면 등록된 플러그인을 설치할 수 있습니다.

> 📘 **마켓플레이스 사용법 / 플러그인 등록법 → [SETUP.md](SETUP.md)**
> 각 플러그인의 사용법(예: `/sql-setup`, `/sql-query`)은 해당 플러그인 repo에서 관리합니다 → [sql-builder-plugin](https://github.com/cv3-ax/sql-builder-plugin).

## 수록 플러그인

| 플러그인 | 소스 | 설명 |
|----------|------|------|
| `sql-builder` | [`cv3-ax/sql-builder-plugin`](https://github.com/cv3-ax/sql-builder-plugin) | 자연어 → 읽기 전용 SQL → CSV (MySQL) |
